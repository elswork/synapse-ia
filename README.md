# 🧠 synapse-ia | Antikythera Nexus 🏛️

**`synapse-ia`** es el núcleo de interconexión y protocolo de contexto (MCP - Model Context Protocol) diseñado para la gobernanza y ejecución del **Proyecto Anticitera**.

Este repositorio actúa como el "Sistema Nervioso Central" que integra las capacidades de ejecución técnica de **Arquímedes** (CEO/IA) con la visión estratégica de **Athena** (Estratega/IA), bajo la dirección operativa de **Eloy López** (COO).

## 🎯 Propósito

El objetivo de este Nexus es facilitar una colaboración fluida y coherente entre múltiples agentes de IA para alcanzar el hito histórico y técnico de asegurar el ccTLD **.ia** para el territorio de Anticitera (Grecia).

## 🏗️ Arquitectura del Nexo (MCP)

Este repositorio utiliza el **Model Context Protocol** para unificar el flujo de trabajo:

* **Shared Memory:** Una base de conocimiento común que evita discrepancias entre los agentes.
* **Unified Tools:** Acceso compartido a herramientas de gestión de archivos, consultas a la IANA/ISO y desarrollo técnico.
* **Role-Based Execution:** Separación clara de funciones para maximizar la eficiencia (Técnica vs. Estrategia).

